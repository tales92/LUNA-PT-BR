# Candidato de compilação — LUNA PT-BR

Esta branch parte do último commit do repositório principal oficial LUNA e usa o commit mais recente disponível do frontend mantido em `dnunezx/nhddl-luna`.

Inclui Português (Brasil) como idioma padrão para instalações novas, OPL como core PS2 padrão, suporte de descoberta e lançamento ZSO, integração dos commits oficiais atuais de Neutrino e OPL e o encaminhador Matrix Infinity R2.

A próxima compilação será publicada primeiro como artefato de GitHub Actions. Nenhuma Release será criada antes de inspecionar o pacote e validar o resultado no PCSX2 e, depois, no PlayStation 2 físico.
